# README images

`picker.webp` and `colours.webp` are real captures of the picker, taken on a
generated demo library (procedural landscapes, no third-party art) and placed
on one of those wallpapers.

`social-preview.jpg` is the GitHub social card (1280×640, under 1 MB).
Committing it does not set it: upload it under **Settings → General → Social
preview**. None of these files ship in the installed extension.
