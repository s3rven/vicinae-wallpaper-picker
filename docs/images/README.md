# Showcase images

`wallpaper-picker-hero.png` is the approved blue-wallpaper showcase used at the
top of the project README. It presents the picker on a black background with a
subtle perspective effect.

`social-preview.jpg` is the corresponding GitHub social card: 1280×640 pixels,
under 1 MB, with a solid black background. To enable it, open the repository's
**Settings → General → Social preview → Edit → Upload an image** and select
this file. Committing an image does not set the repository's social preview.

The images are promotional renders based on a captured picker window. Embedded
metadata has been removed. They are documentation assets and are not included
in the installed extension's backend bundle.
